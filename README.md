# MALL-WAY

## 아르온 백화점 키오스크

Windows x64에서 실행하는 WPF · .NET Framework 4.8 프로젝트입니다.

## 실행

Visual Studio에서 `MALL-WAY.sln`을 열고 .NET 데스크톱 개발 워크로드와 .NET Framework 4.8 개발자 팩을 설치한 환경에서 F5를 누릅니다. 명령줄에서는 `dotnet build MALL-WAY.sln`으로 빌드할 수 있습니다.

Debug 빌드의 실행 파일은 `MALL-WAY/bin/Debug/net48/win-x64/MALL-WAY.exe`입니다. 다른 폴더에서 시연할 때는 설정과 라이브러리를 포함한 출력 폴더 전체를 복사합니다. 첫 실행에는 출력 폴더에 쓸 수 있어야 합니다.

## 수요일 구현

- WPF 화면은 MVVM Light의 ViewModel에 바인딩합니다. 앱 시작 시 SimpleIoc에 설정, DB 접근 클래스, ViewModel을 등록하고 CommonServiceLocator로 ViewModel을 가져옵니다.
- Newtonsoft.Json으로 실행 파일 옆의 `kiosk-settings.json`을 읽습니다. 백화점 이름, SQLite 파일 경로, 기본 표시 층, 출발 노드 ID를 설정합니다. 상대 DB 경로의 기준은 실행 파일 폴더입니다.
- 첫 실행 때 `Data/initialize.sql`로 SQLite 파일을 생성합니다. 이후 실행은 기존 데이터를 사용합니다. 지도와 매장 정보는 WPF에서 SQLite 파일에 직접 연결해 읽습니다.
- DB에는 1층 푸드코트, 2층 패션, 3층 영화관과 편의시설, 매장 입구, 복도 및 층간 연결을 저장합니다. 각 간선은 양방향 이동을 의미하고, 양수 비용을 가집니다.
- 기본 1층 지도에서 매장 및 편의시설 배치, 중앙 엘리베이터, 동쪽 에스컬레이터, 1층 키오스크의 현재 위치를 볼 수 있습니다.

## 목요일 구현

- 층 버튼은 SQLite의 `Floors` 목록으로 생성합니다. 버튼을 누르면 해당 층의 지도를 다시 조회하고 ViewModel의 변경 알림으로 제목과 지도를 갱신합니다. 현재 위치 표식은 키오스크가 있는 1층에 표시합니다.
- 왼쪽 검색창은 전체 층의 매장·시설 이름을 부분 검색합니다. 카테고리와 이름 조건을 함께 적용하며, 검색 초기화 버튼으로 두 조건을 해제할 수 있습니다. 검색 결과가 없으면 안내 문구를 표시합니다.
- 검색 결과 또는 지도 위 매장을 누르면 해당 층으로 이동하고 목적지를 금색으로 강조합니다. 오른쪽에는 이름, 카테고리, 층과 구역, 영업시간을 표시합니다.
- 화장실·수유실·고객센터·주차장 연결 통로 바로가기는 검색창과 카테고리를 함께 설정합니다. 여러 층에 있는 화장실은 각 층의 결과를 구분해서 선택할 수 있습니다.
- 선택한 목적지는 `SelectedDestinationNodeId`로 입구 ID를 제공합니다. 수동으로 층을 바꾸거나 새 검색 조건에서 선택한 목적지가 제외되면 상세와 강조 표시를 해제합니다.
- 수요일의 DB 버전 1을 그대로 사용합니다. 기존 `department.db`를 삭제하거나 초기화 SQL을 다시 실행할 필요가 없습니다.
- 길찾기 버튼은 준비 중 상태로 표시합니다. 금요일에 다익스트라 계산, 지도 위 경로, 엘리베이터·에스컬레이터 탑승 및 하차층 안내를 연결합니다.

## 목요일 확인 순서

1. 앱을 열어 1층 지도와 빨간 현재 위치 표식을 확인합니다. 2F, 3F를 차례로 누르면 해당 지도가 표시되고, 현재 위치 표식은 1F로 돌아왔을 때 표시됩니다.
2. 검색창에 `모노`를 입력하고 결과의 모노핏을 누릅니다. 2층 전환, 금색 강조, 영업시간을 확인합니다.
3. 검색 초기화 후 카테고리를 패션으로 선택하면 네 매장이 나옵니다. `온결`을 입력하면 온결웨어 한 곳으로 좁혀집니다.
4. 화장실 바로가기를 누르면 기존 검색 조건이 바뀌고 세 층의 화장실이 나옵니다. 3층 결과를 선택하면 3층 지도의 화장실이 강조됩니다.
5. 수유실, 고객센터, 주차장 연결 통로도 같은 방식으로 확인합니다. 지도에서 매장을 직접 선택해도 상세가 표시됩니다.
6. 존재하지 않는 매장명을 입력하면 결과 없음 안내가 나오고 이전 목적지 선택이 해제됩니다. 검색 초기화 후 다시 선택할 수 있습니다.
